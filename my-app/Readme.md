# Next Level Gaming

## 1. Application Overview

Next Level Gaming is a gaming and esports application designed to help customers
view gaming services, check prices, calculate fees, make bookings and contact
the gaming centre.

The application provides a simple and user-friendly interface with a gaming
and esports theme.

---

## 2. Purpose of the Application

The purpose of the application is to make it easier for customers to:

- View available gaming services
- Check booking prices
- Calculate gaming fees
- Create an account
- View available plans
- Find venues
- Contact the gaming centre
- View frequently asked questions
- Complete a booking and payment process

---

## 3. Main Features

The application contains the following screens:

1. Home
2. About Us
3. Overview
4. Booking Prices
5. Payment
6. Contact Us
7. FAQ
8. Calculate Fees
9. Sign Up
10. Plans
11. Venues

---

## 4. Functionality

### Home
Provides an introduction to Next Level Gaming and displays information about
gaming and esports activities.

### About Us
Provides information about the gaming centre and its facilities.

### Overview
Displays the different gaming services available to customers.

### Booking Prices
Allows users to view the prices of the available gaming experiences.

### Payment
Provides a basic booking summary and payment interface.

### Contact Us
Allows users to view contact information and send a message.

### FAQ
Provides answers to common questions about the gaming centre.

### Calculate Fees
Allows users to enter the number of gaming hours and calculate the estimated
cost.

### Sign Up
Allows new users to enter their details and create an account.

### Plans
Displays different membership plans and their features.

### Venues
Displays information about available gaming venues.

---

## 5. Navigation

The application contains a menu button (☰) that allows users to move between
the different screens.

The navigation system connects the main screens so that users can easily access
different sections of the application.

## 7. Design

The application uses a dark gaming/esports design.

The main design elements include:

- Black background
- Dark purple panels
- Pink/magenta accents
- White headings
- Simple buttons and cards
- Gaming and esports themed layout

The interface was designed to be simple and easy for customers to navigate.
